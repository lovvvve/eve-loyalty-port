# 分诊标签

这些技能使用五个规范分诊角色。本文件将这些角色映射到本仓库问题跟踪器实际使用的标签字符串。

| `mattpocock/skills` 中的标签 | 本跟踪器中的标签  | 含义                     |
| ---------------------------- | ----------------- | ------------------------ |
| `needs-triage`               | `needs-triage`    | 等待维护者评估此问题     |
| `needs-info`                 | `needs-info`      | 等待报告者补充信息       |
| `ready-for-agent`            | `ready-for-agent` | 规格完整，可交由代理处理 |
| `ready-for-human`            | `ready-for-human` | 需要人工实施             |
| `wontfix`                    | `wontfix`         | 不会处理                 |

当技能提到某个角色（例如“应用可交由代理处理的分诊标签”）时，使用表中对应的标签字符串。

如需匹配现有词汇，请编辑右侧“本跟踪器中的标签”列。
